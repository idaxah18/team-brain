# Cómo trabajamos

1. **team-brain** (este repo): notas, decisiones, KEYWORDS. Sincronía con **Git** (`pull` / `push`).
2. **PyR**: código (ej. Laravel). Archivo **CONTEXT.md** apunta aquí.
3. **Obsidian**: abrir esta carpeta como vault.
4. **Cursor**: abrir `team-brain` solo contexto, o `PyR.code-workspace` para contexto + código.

Antes de implementar: buscar palabra clave en [[index/KEYWORDS]].
