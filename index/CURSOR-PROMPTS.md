# Prompts para Cursor

## Cargar contexto de un proyecto

```text
Palabra clave: <nombre-en-KEYWORDS>.
Sigue AGENTS.md. Resume en bullets qué debemos respetar antes de codificar.
```

## Guardar contexto de un chat en el vault

```text
Resume este chat en projects/<slug>/contexto-FECHA.md.
Actualiza projects/<slug>/overview.md y añade fila en index/KEYWORDS.md.
No pongas secretos ni datos personales. El código va en el repo PyR, no aquí.
```
