# Proyectos

Cada producto o entrega tiene su carpeta:

```text
projects/<nombre>/
  overview.md          ← objetivo, alcance, decisiones
  contexto-YYYY-MM-DD.md   ← resumen de chats o reuniones
```

Luego registra palabras en `index/KEYWORDS.md`.

Ejemplo próximo: `projects/formulario-web/` (contexto del formulario Laravel en PyR).
