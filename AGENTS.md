# Agente — team-brain (vault compartido)

Este repositorio es el **segundo cerebro** del equipo. **No contiene código de producto** (eso vive en repos hermanos como `PyR`).

## Protocolo de contexto (obligatorio)

1. Abre `index/KEYWORDS.md` y localiza la fila por palabra clave.
2. Lee solo "Leer primero" y "Luego" (máx. **5 notas**).
3. No leas todo `inbox/` ni `attachments/` salvo petición explícita o archivo citado.
4. Si falta contexto, crea nota en `domains/` o `projects/` y actualiza `KEYWORDS.md` + MOC.

## Convenciones

- Wikilinks `[[ruta/sin-extension]]`, frontmatter YAML, archivos `kebab-case.md`.
- `inbox/` captura; `domains/` verdad estable; `projects/<slug>/` contexto por producto o entrega.

## Código

Implementación en repos de código (ej. `../PyR/apps/`). Este repo solo documenta **qué** y **por qué**; el otro repo tiene el **cómo** en código.

## Obsidian

Abrir esta carpeta como vault. Entrada: `MOC-Home.md`. Guía para presentar: `docs/GUIA-PRESENTACION.md`.
